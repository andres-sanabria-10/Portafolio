## En una frase

Un **pipeline de datos** lleva los datos desde donde nacen hasta donde alguien los usa, limpiándolos en el camino, de forma automática y repetible. La mejor manera de entenderlo es seguir un solo dato de principio a fin.

## El viaje, etapa por etapa

Esta guía es sintética, pero sus problemas son los que llegan de verdad de una API: espacios en la llave, un estado con el vocabulario de cada transportadora, abreviaturas en la ciudad, un peso en cero y una fecha en formato local. Avanza con los botones o con las flechas del teclado.

## ¿Y en la nube?

El pipeline del recorrido corre on-premise, con Python y SQL Server. Las etapas son las mismas en la nube; solo cambian las piezas. Así lo armaría en AWS, que es lo que estoy aprendiendo:

| Etapa | On-premise | En AWS |
| --- | --- | --- |
| Ingesta programada | Python + Programador de tareas | AWS Lambda + Amazon EventBridge |
| Raw | Tabla en SQL Server | Amazon S3, en Parquet y particionado por fecha |
| Staging | Vistas en SQL Server | AWS Glue (catálogo y trabajos de limpieza) |
| Modelo y consulta | Vistas en SQL Server | Amazon Athena (o Redshift si crece) |
| Consumo | Power BI | Power BI o Amazon QuickSight |

La idea de fondo no cambia: guardar el crudo, limpiar una sola vez con reglas y dejar un modelo con un grano claro.

## Los errores que este recorrido evita

- **Limpiar en el tablero.** Si cada reporte limpia a su manera, dos tableros dan dos cifras para lo mismo.
- **Rellenar lo que no se sabe.** Un peso en cero o una fecha `1900-01-01` parecen datos y arruinan los promedios; lo que no se conoce es `NULL`.
- **Contar eventos como si fueran guías.** Una guía con tres estados no son tres envíos.
- **Comparar promedios generales.** Una transportadora que va a destinos lejanos siempre se verá más lenta si no se compara por ruta.

## Cómo lo apliqué

Este recorrido es, en pequeño, el del [proyecto de trazabilidad](/proyectos/): un pipeline que consume las APIs de 7 transportadoras cada 4 horas, limpia en staging y deja una fila por guía para responder dónde se demora cada envío y quién cumple.
