## En una frase

Un **pipeline de datos** es una serie de pasos automáticos que lleva los datos desde donde nacen hasta donde alguien los usa, limpiándolos y transformándolos en el camino, de forma **repetible** y **confiable**.

## Una analogía: el acueducto

Piensa en el agua de tu casa. Se capta en un río (la **fuente**), se bombea por tubos (la **ingesta**), pasa por una planta de tratamiento (la **transformación**), se guarda en un tanque (el **almacenamiento**) y sale por el grifo (el **consumo**). Nadie tiene que acarrear baldes: funciona solo, todos los días, y alguien vigila la calidad del agua en cada paso.

Un pipeline hace lo mismo con los datos. Y como en el acueducto, lo importante no es que el agua llegue una vez, sino que llegue siempre y limpia.

## Un ejemplo pequeño en Python

Un pipeline de verdad tiene más piezas, pero la idea cabe en tres funciones: extraer, transformar y cargar. Lo importante está en la carga: usa la guía como llave, así que correrlo dos veces no duplica nada.

```python
import sqlite3

import pandas as pd


def extraer(ruta: str) -> pd.DataFrame:
    return pd.read_csv(ruta, dtype=str)


def transformar(crudo: pd.DataFrame) -> pd.DataFrame:
    limpio = crudo.assign(
        guia=crudo["guia"].str.strip(),                 # llaves sin espacios
        estado=crudo["estado"].str.strip().str.lower(),
        fecha=pd.to_datetime(crudo["fecha"], errors="coerce"),
    )
    return limpio.dropna(subset=["guia", "fecha"]).drop_duplicates("guia", keep="last")


def cargar(datos: pd.DataFrame, conexion: sqlite3.Connection) -> None:
    # INSERT OR REPLACE por llave primaria: volver a correr no duplica filas.
    conexion.executemany(
        "INSERT OR REPLACE INTO envios (guia, estado, fecha) VALUES (?, ?, ?)",
        datos[["guia", "estado", "fecha"]].astype(str).itertuples(index=False),
    )
    conexion.commit()


if __name__ == "__main__":
    with sqlite3.connect("envios.db") as conexion:
        conexion.execute(
            "CREATE TABLE IF NOT EXISTS envios (guia TEXT PRIMARY KEY, estado TEXT, fecha TEXT)"
        )
        cargar(transformar(extraer("envios.csv")), conexion)
```

## Errores comunes

- **Que alguien tenga que correrlo a mano.** Si depende de que una persona se acuerde, no es un pipeline.
- **Duplicar al volver a correr.** Sin una llave y una carga idempotente, cada reintento suma filas repetidas.
- **Traer todo cada vez.** Con pocas filas no se nota; con millones, el pipeline se vuelve lento y caro.
- **Limpiar en el tablero.** Si cada reporte limpia a su manera, dos tableros dan dos cifras distintas para lo mismo.
- **No validar.** Un pipeline que falla en silencio es peor que uno que se detiene y avisa.
